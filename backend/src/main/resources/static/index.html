Quick Test

These are the most useful flows if you want to check whether the backend server is alive and whether the formulas return the right numbers.

Default Emissions

Tests `/api/cbam/default-emissions` with real backend data.

Actual Emissions

Tests `/api/cbam/actual-emissions`. Activities are entered as JSON so you can quickly change them.

Compare Default Vs Measured

Use this when you already have both values: the default specific emissions and the measured actual specific emissions. The frontend can fill these automatically from the last default and actual calculations.

Run both default emissions and actual emissions to auto-fill the comparison endpoint.

Advanced Certificates

Tests `/api/cbam/advanced-certificates` when you want the full surrender obligation logic.

Validate Report

Useful if you want to test report consistency rules and see validation errors immediately.
